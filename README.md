# CampusPe Landing Page

A responsive CampusPe landing page built with Next.js 14, React, and CSS, based on the provided Figma screenshots.

## Features
- Responsive navigation for desktop and mobile
- Hero section with gradient headline and floating cards
- College, job seeker, and hiring feature cards
- Statistics and partner-logo strip
- Opportunity discovery dashboard with working category filters
- Resume upload call-to-action demo
- College and employer feature sections
- Interactive sign-in / sign-up modal
- Hover, focus, active, and reduced-motion states

## Run locally
Requires Node.js 18.17 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Notes
This is a frontend demo. Authentication, email submission, real resume upload, and job listings need backend/API integration before production use. Partner names/logos are illustrative placeholders and should be replaced with approved brand assets. No live deployment or GitHub repository is included in this ZIP.
